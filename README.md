# Common Chinese Characters Learner

A web-based tool for learning the 7,000 common Chinese characters from the Modern Chinese Common Characters List.

## Features

- Learn all 7,000 common Chinese characters
- Stroke order animations
- Pinyin and English meanings
- Spaced repetition system
- Progress tracking

## Tech Stack

- Vue 3
- Vite
- Tauri for desktop app
